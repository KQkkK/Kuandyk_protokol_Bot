# Бот поручений (@Kuandyk_protokol_bot)

Telegram-бот для протокола поручений. Руководитель надиктовывает поручение голосом,
бот разбирает «кому / что / срок / лично или в группу», показывает карточку на
согласование и после подтверждения отправляет исполнителю — в личку или в общую группу.
Сотрудник отвечает кнопками «Принял», «Уточнить», «Продление срока», «Исполнил»;
продление и исполнение вступают в силу только после согласования руководителя.

Подробно — экраны, цвета статусов, все тексты сообщений: [DESIGN.md](DESIGN.md).

## Развернуть на другом компьютере (Windows)

Время: 10–15 минут. Понадобится доступ к аккаунту GitHub `assetuaissov-dev`
(репозиторий приватный) и токен бота.

### ⚠️ Прочитайте до начала

1. **Бот может работать только на одном компьютере одновременно.** Если запустить его
   на двух ПК сразу, Telegram выдаст ошибку `Conflict: terminated by other getUpdates request`,
   и оба будут работать с перебоями. Перед запуском на новом ПК закройте окно бота на старом.
2. **База данных не хранится на GitHub** — там только код. Список подключённых
   сотрудников и групп лежит в файле `data\bot.db` на том ПК, где бот работал.
   Чтобы перенести их, скопируйте папку `data` со старого ПК в папку проекта на новом
   (флешкой, через облако). Не перенесли — сотрудникам придётся подключиться заново.
3. **Токен бота — это ключ от бота.** Не отправляйте его в чаты и почту, не выкладывайте
   на GitHub. Он хранится только в файле `.env`, который в GitHub не попадает.

### Шаг 1. Установите Python и Git

Откройте **PowerShell** (Пуск → наберите «PowerShell» → Enter) и выполните по очереди:

```powershell
winget install --id Python.Python.3.12 -e --scope user
winget install --id Git.Git -e
```

Если Windows спросит разрешение — нажмите «Да». **После установки закройте PowerShell
и откройте заново**, иначе новые программы не будут видны.

Проверка — обе команды должны показать версию:

```powershell
python --version
git --version
```

> Если `python --version` открывает Microsoft Store или ничего не выводит — Python
> не установился. Повторите первую команду.

### Шаг 2. Скачайте код с GitHub

```powershell
mkdir $HOME\Projects -Force
cd $HOME\Projects
git clone https://github.com/assetuaissov-dev/Kuandyk_protokol_Bot.git
```

Репозиторий приватный: откроется окно **«Connect to GitHub»** → **Sign in with your browser**
→ в браузере **Authorize**. Это нужно один раз на каждом компьютере.

Код окажется в папке `C:\Users\<ваше имя>\Projects\Kuandyk_protokol_Bot`.

### Шаг 3. Установите бота

Откройте эту папку в Проводнике и дважды щёлкните **`setup.bat`**.

Он сам создаст окружение Python, поставит библиотеки и создаст файл `.env`.
В конце должно быть: `Готово. Дальше: заполните .env и запустите start.bat`.

### Шаг 4. Впишите токен

Откройте файл `.env` в папке проекта (правой кнопкой → Открыть с помощью → Блокнот
или VS Code) и заполните:

```
TELEGRAM_BOT_TOKEN=сюда_токен_бота
MANAGER_TELEGRAM_ID=сюда_ваш_ID
```

- **Токен**: скопируйте из `.env` на старом ПК. Если его нет — в Telegram откройте
  @BotFather → `/mybots` → выберите бота → **API Token**.
- **Ваш ID**: скопируйте со старого ПК. Если не знаете — оставьте пустым и см. шаг 5.

Без пробелов и кавычек вокруг значений. Сохраните файл (Ctrl+S).

> ⚠️ ID руководителя — это **ваш личный** ID, а не число в начале токена (то ID бота).
> Если перепутать, бот не запустится и прямо об этом скажет.

### Шаг 5. Запустите

Закройте окно бота на старом ПК, если оно открыто. Затем дважды щёлкните **`start.bat`**.

Должна появиться строка `Бот @Kuandyk_protokol_bot запущен`. Окно не закрывайте —
пока оно открыто, бот работает.

**Если `MANAGER_TELEGRAM_ID` пустой**, бот запустится в режиме настройки: напишите ему
в Telegram `/start`, он ответит «Ваш Telegram ID: …». Впишите это число в `.env`,
закройте окно бота и снова запустите `start.bat`.

### Шаг 6. Проверьте

Напишите боту `/start`. Должно прийти: «Здравствуйте! Вы руководитель.» и ссылка
для сотрудников. Команда `/staff` покажет подключённых сотрудников.

## Обновить код до последней версии

Закройте окно бота, затем в PowerShell в папке проекта:

```powershell
git pull
```

И снова запустите `setup.bat` (на случай новых библиотек) и `start.bat`.

## Проверки

Автоматические проверки базы (подключение, двойное нажатие, отключение):

```powershell
.venv\Scripts\python -m unittest discover -s tests -t .
```

Должно закончиться словом `OK`.

## Если что-то не работает

| Что видите | Что делать |
|---|---|
| `Ошибка настройки: Не задан TELEGRAM_BOT_TOKEN` | Токен не вписан в `.env` или файл не сохранён. Шаг 4 |
| `В MANAGER_TELEGRAM_ID указан ID самого бота` | Очистите поле, запустите бота, напишите `/start` — получите свой ID. Шаг 5 |
| `Conflict: terminated by other getUpdates request` | Бот запущен где-то ещё. Закройте второе окно |
| `Unauthorized` | Токен неверный или его перевыпустили в @BotFather. Возьмите новый |
| `'python' не является внутренней или внешней командой` | Python не установлен или PowerShell не перезапущен. Шаг 1 |
| Бот молчит в Telegram | Проверьте, что чёрное окно `start.bat` открыто и в нём нет ошибок |
| Сотрудники пропали | Не перенесли папку `data` со старого ПК. См. «Прочитайте до начала», п. 2 |

## Устройство проекта

```
bot/
  __main__.py     запуск бота
  config.py       чтение настроек из .env
  db.py           база SQLite (data/bot.db)
  filters.py      проверка «это руководитель?»
  onboarding.py   подключение сотрудников, /staff
  groups.py       подключение групп, /groups
  setup_mode.py   режим настройки — бот сообщает людям их ID
tests/            автоматические проверки
DESIGN.md         экраны, статусы, цвета, тексты сообщений
.env.example      образец настроек (без значений)
setup.bat         установка в один щелчок
start.bat         запуск
```

**Стек**: Python 3.12, aiogram 3 (библиотека для Telegram-ботов), SQLite.
Впереди: распознавание голоса (OpenAI), разбор поручения (Claude Haiku),
размещение на сервере ps.kz в Казахстане.

**Секреты**: только в `.env`, который в `.gitignore`. В репозиторий не попадают
`.env`, `.venv/`, `data/`.
